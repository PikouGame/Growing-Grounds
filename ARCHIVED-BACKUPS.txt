Status

replacement archive will pass moderation.

No automatic companion, Python runtime, backup scripts or nested runtime ZIPs
are included in the current mod package. No executable has been disguised or
renamed. The backup-only source is retained in Git, not in the active tree.

Existing archives
Nothing in this removal deletes or rewrites save files, archive directories
or existing GG ZIP backups. Their restore tool and guide remain available
from the archived branch. Restore only with the game/server stopped, into a
separate destination first, following that archived guide.

Proton/server launcher wrapper; preserve config.lua and world-settings.ini;
replace the old mod folder rather than merge it. Keep existing archives.

Current isolated development sessions may still use the old managed launcher
until their next coordinated migration. Archiving the source does not alter
