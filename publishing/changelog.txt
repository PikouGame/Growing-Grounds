0.1.2-alpha — room to grow, a moment to celebrate

Known visual issue: the celebration can still start late after closing the Palbox. This does not postpone the actual base-radius upgrade. A new lightweight change observer is included; its improvement during a natural upgrade has not yet been verified in game.

- A terrain-following blue wave travels from the Palbox to the old boundary, then triggers the expansion/bounce and rising glow.
- The outward wave now takes 2.4 seconds; the rising effect defaults to 6 metres.
- After an upgrade, preparation runs while Base Upgrade is open. Playback waits for the screen to close and setup to finish, with no fixed countdown.
- Fresh terrain is sampled for every animation. No terrain cache between plays or speculative menu/nearby preloading.
- Faster bounded preparation and event-maintained engine-object lists address the reported animation setup delay and five-second freezes on the test setup.
- A lightweight 250 ms check of tracked base levels/radii avoids waiting for the five-second reconciliation when native hooks miss a change.
- Configurable growth and cap, per-world settings, a hard 200% ceiling, and spacing-aware growth across guilds.
- Server-authored next-range preview, preserved native value columns, and a refined circle/four-arrow icon.

Update both host/server and clients. Preserve your config.lua preferences and
world-settings.ini files. New cap/spacing rules may shrink older expanded bases,
so please keep a world backup before updating. UE4SS is required separately.

Checked in game: radius replication, 140% -> 145% preview and screen-close replay.
World Settings flows, placement, expanded-area work/resources, full reset lifecycle,
other range mods and broader hardware/OS combinations still need more testing.

We'd love to hear how it feels in your world. Leave a comment, share a clip or
report a bug so we can investigate and improve it:
https://github.com/PikouGame/Growing-Grounds/issues

0.1.1-alpha — upgrade celebration

- Smooth boundary expansion with a slight bounce after a server-confirmed base upgrade.
- Terrain-shaped rising cyan line with a continuous glow trail, an earlier flash, and a shared fade while still moving.
- Cached game-object lookups and bounded terrain/mesh setup reduce replay overhead.
- Visual-only Ctrl+Shift+F7 preview; debug logging/hot reload disabled by default.
- Original 5% growth formula, server authority and percentage reward row retained.

Update the BaseRangeGrowth folder and restart the client. Existing 0.1.0 servers
remain compatible with the client animation. No UE4SS loader is bundled.
Tested through in-game replay; wider hardware performance, expanded-ring gameplay,
new-base/reset lifecycle and native Windows OS execution remain unverified.

0.1.0-alpha — first public test build

- Adds 5% of the original radius per base level after level 1.
- Server-controlled radius with client boundary updates.
- Native Base Range reward row, percentages and original four-arrow icon.
- Repairs label/icon resets when the native widget reconstructs.
- Includes opt-in resetToVanilla configuration.

Alpha: expanded-ring gameplay, lifecycle/reset and Workshop deployment remain
unverified. Back up your world before testing. See the description for details.
