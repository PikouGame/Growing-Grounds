Growing Grounds (GG)

Give your base room to grow as its level increases. Each level after level 1
adds 5% of the original base radius, without compounding.

At level 8, a default 35 m base becomes 47.25 m. The native Base Upgrade
screen gains a Base Range reward row with a four-arrow icon and current/next
percentages, for example 135% -> 140%.

ALPHA 0.1.0 — please back up your world before testing.

The server owns the radius. Install the mod on the server/host and on clients
that need the UI and boundary display. UE4SS for Palworld is required and is
not bundled. This is a Lua mod; PalSchema is not required.

MANUAL INSTALL
Close the game/server normally. Extract the BaseRangeGrowth folder into your
existing UE4SS Mods directory. Keep the internal folder name BaseRangeGrowth.
For a manual loader this is Pal/Binaries/Win64/ue4ss/Mods/.
For a Workshop-installed loader this is Mods/NativeMods/UE4SS/Mods/.
Use one existing loader installation; do not install a second copy.
Restart the server and clients, then open Base Upgrade. Allow up to five seconds
for the row to appear. Ctrl+Shift+F10 writes a diagnostic check to UE4SS.log.

COMPATIBILITY AND TESTING
Observed on Palworld v1.0.5.102999, UE4SS Palworld fork 2281fa31, with Windows
executables running through Wine/Proton. The level-8 server radius, replicated
client radius and boundary were observed. The player confirmed that the reward
label and icon remain correct after repeated menu reopening. Lua regression
tests pass. Native Windows OS execution has not been tested in this project.

NOT YET VERIFIED
Building placement, stored-resource use and Pal work throughout the expanded
ring; live base upgrades and new Palboxes; complete reset/uninstall lifecycle;
other mods that change base radius; the Workshop deployment route.
This alpha is not a claim of fully tested expanded-base gameplay.

KNOWN LIMITS
The extra row is currently English. On a remote server whose radius does not
match the growth curve, the next value shows --. At base level 1 it also shows
-- because the vanilla radius alone cannot establish server mod support.
The next value is hidden at the maximum base level.

REMOVAL
The expanded radius can be saved in your world. Removing the files alone does
not guarantee a reset. First set resetToVanilla=true in the server's config.lua,
restart and load the world, verify the original radius in UE4SS.log, save, and
then remove the mod. Buildings in the added ring may be outside the base after
shrinking. Keep a backup; the full reset lifecycle remains unverified.
